# Khái niệm Cốt lõi về Cơ sở Dữ liệu

| Khái niệm | Định nghĩa thực tế (Bản chất) |
|---|---|
| **Data (Dữ liệu)** | Là data, chưa có ngữ cảnh/ý nghĩa (Ví dụ: con số "30"). |
| **Information (Thông tin)** | Là Data ĐÃ được gắn ngữ cảnh, mang lại ý nghĩa (Ví dụ: "30 tuổi"). |
| **Database (Cơ sở dữ liệu)** | Tập hợp các dữ liệu có liên quan, được sắp xếp có logic để phục vụ một mục đích cụ thể. |
| **DBMS (Hệ quản trị CSDL)** | Phần mềm dùng để tạo, thao tác và quản lý Database (Ví dụ: MySQL, PostgreSQL). |
| **Các loại Database** | SQL (Relational) và NoSQL (Non-relational). |
