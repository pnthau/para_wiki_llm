# Database System (Hệ thống CSDL) và Relational DB

| Khái niệm | Định nghĩa thực tế (Bản chất) |
|---|---|
| **Database System (Hệ thống CSDL)** | Là toàn bộ hệ sinh thái bao gồm: Ứng dụng (App/Queries) + Phần mềm quản lý (DBMS) + Ổ cứng lưu trữ (Stored Database & Meta-data). |
| **Relational DB (CSDL Quan hệ)** | Tổ chức dữ liệu thành các Bảng (Table), và móc nối với nhau qua các mối quan hệ (Ví dụ: 1 Khách hàng - N Hợp đồng). |
