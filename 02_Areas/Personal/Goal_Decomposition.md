# [[Goal_Decomposition]] (Cornell Notes)

| Cue | Notes |
| --- | --- |
| **Hiệu ứng Choáng ngợp** | - Mục tiêu lớn gây "tê liệt" cho [[Prefrontal_Cortex]] do khối lượng tính toán quá tải.<br>- Não kích hoạt cơ chế trì hoãn để bảo vệ bản thân khỏi sự mơ hồ. |
| **Phân rã theo Thời gian** | - Chia mục tiêu dài hạn thành các cột mốc: Tháng → Tuần → Ngày.<br>- Ví dụ: 3 tháng học Python → Tuần 1: Cú pháp cơ bản → Ngày 3: Viết 5 vòng lặp. |
| **Phân rã theo Cấu trúc** | - Chia kết quả lớn thành các bộ phận cấu thành.<br>- Ví dụ: Bài báo 3000 từ → Mở bài (500) + 3 Luận điểm (2100) + Kết bài (400). |
| **Nguyên tắc 15-45 phút** | - Phân rã cho đến khi mỗi nhiệm vụ chỉ mất 15-45 phút.<br>- Phù hợp với [[Ultradian_Rhythm]] (nhịp siêu nhịp) để duy trì tập trung sâu. |
| **Cây mục tiêu ([[Goal_Tree]])** | - Trực quan hóa quá trình phân rã (WBS - [[Work_Breakdown_Structure]]).<br>- Trả lời câu hỏi: "Để đạt mục tiêu cấp trên, tôi cần làm gì ở cấp dưới?" |
| **Bẫy tâm lý** | - **Quá chi tiết**: Tránh chia nhỏ < 15 phút (gây loãng).<br>- **Thiếu linh hoạt**: Cần vùng đệm 20% cho biến cố.<br>- **Quên mục tiêu gốc**: Cần check lại cây mục tiêu hàng tuần. |

## Summary
Kỹ thuật [[Goal_Decomposition]] là cầu nối giữa tham vọng và hành động thực tế bằng cách giảm tải nhận thức cho [[Prefrontal_Cortex]], biến mục tiêu choáng ngợp thành các nhiệm vụ 15-45 phút mà não bộ không thể từ chối.
