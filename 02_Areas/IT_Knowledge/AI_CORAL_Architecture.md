# 🤖 CORAL: Self-Evolving Multi-Agent Architecture

## 📌 Overview
CORAL (Collaborative Objective-Reinforced Adaptive Learning) là một kiến trúc Đa tác nhân mới được giới thiệu vào giữa năm 2026. Nó cho phép các agent tự động phân tích hiệu suất của nhau và đề xuất các chỉnh sửa mã nguồn cho đồng nghiệp để tối ưu hóa Workflow tổng thể.

## 🗝️ Key Features
- **Meta-Review Loop**: Agent A review code của Agent B và tự động apply hotfix nếu được phép.
- **Dynamic Skill Synthesis**: Các agent tự tạo ra các "Skill" mới (tương tự như Gemini CLI Skills) khi đối mặt với các bài toán chưa có tiền lệ.
- **Quota-Aware Execution**: Tự động điều phối tác vụ dựa trên giới hạn tài nguyên còn lại.

## 🚀 Application in Nexus
Nexus v8.2 tích hợp các nguyên lý của CORAL để tự động hóa chu trình `nexus_nightly_evolution.ps1`.
