# Title: {{title}}

| 💡 Từ khóa / Câu hỏi (Cue) | 📝 Nội dung ghi chú (Notes) |
| :--- | :--- |
| **Kế thừa là gì?** | Là cơ chế class con dùng lại thuộc tính, phương thức của class cha. |
| **Mục đích?** | 1. Tái sử dụng code.<br>2. Mở rộng chức năng.<br>3. Ghi đè (Override). |
| **Code Example** | `class Dog extends Animal { }` |

<br>

| 🎯 Tổng kết (Summary) |
| :--- |
| Kế thừa giúp tái sử dụng code và tổ chức các class theo dạng phân cấp. Java chỉ hỗ trợ đơn kế thừa (Single Inheritance) thông qua từ khóa `extends`. |
