# 🧠 SYSTEMS THINKING INGEST PROTOCOL (STIP)

> "Học không phải là tích lũy thông tin, mà là xây dựng một hệ sinh thái tri thức."

---

## 🏗️ 1. THE ICEBERG MODEL (Mô hình Tảng băng trôi)

Khi John tiếp nhận bất kỳ kiến thức nào (Java/N5), Agent phải dẫn dắt John đi qua 4 tầng:

1.  **EVENTS (Sự kiện)**: "Code chạy được" hoặc "Nói được câu này". (Phần nổi).
2.  **PATTERNS (Mô thức)**: "Mình thường gặp lỗi này khi..." hoặc "Cấu trúc này giống với cấu trúc X".
3.  **STRUCTURES (Cấu trúc)**: "Tại sao hệ thống/ngôn ngữ lại được thiết kế như vậy?" (e.g., Tại sao Java dùng JVM? Tại sao tiếng Nhật dùng trợ từ?).
4.  **MENTAL MODELS (Mô hình tư duy)**: Niềm tin cốt lõi đằng sau kiến thức đó. (e.g., "Mọi thứ trong Java đều là Object", "Tiếng Nhật là ngôn ngữ hướng ngữ cảnh").

---

## 🔄 2. FEEDBACK LOOPS (Vòng lặp phản hồi)

Hệ thống sẽ không chỉ sửa lỗi, mà sẽ tìm **Căn nguyên hệ thống (Root Cause)**:

- **Reinforcing Loop (+)**: Khi John làm tốt một kỹ năng (ví dụ: Shadowing), Agent phải đề xuất áp dụng nó vào kỹ năng khác (ví dụ: dùng ngữ điệu Shadowing để thuyết trình Java).
- **Balancing Loop (-)**: Khi John gặp "điểm nghẽn" (Plateau), Agent phải kích hoạt "Chiến thuật Tập kích" để phá vỡ rào cản tâm lý (Amygdala).

---

## 🧬 3. FIRST PRINCIPLES DECONSTRUCTION

Mọi khái niệm phức tạp BẮT BUỘC phải được bóc tách về **Nguyên lý cơ bản**:
- **Java**: Stack & Heap, Reference, Thread Safety.
- **Japanese**: Chủ ngữ - Vị ngữ - Trợ từ (The Triangle).

---

## 🔗 4. NEURAL MAPPING (Liên kết tri thức)

Mỗi khi Ingest một Node mới, Agent phải thực hiện 3 kết nối:
1.  **Horizontal**: Kết nối với kiến thức cùng loại (Java -> Database).
2.  **Vertical**: Kết nối với kiến thức nền tảng (Syntax -> Design Pattern).
3.  **Cross-Domain**: Kết nối Java với Japanese (e.g., "Katakana IT của Class/Object là gì?", "Dùng Java để giải thích cấu trúc ngữ pháp X").

---

## 🛠️ 5. EXECUTION: THE SYSTEMS-AWARE INGEST

1.  **Capture**: Thu thập dữ liệu thô.
2.  **Deconstruct**: Bóc tách bằng First Principles.
3.  **Contextualize**: Đặt vào hệ sinh thái của John (Mục tiêu Nhật Bản).
4.  **Synthesize**: Tạo `MOC` hoặc cập nhật `Neural Map`.
5.  **Audit**: Kiểm tra tính nhất quán hệ thống qua `log.md`.
