| Khái niệm                                        | Nội dung chi tiết                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :----------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Library**<br>*(Thư viện)*                      | - Là các đoạn code được viết sẵn để giải quyết một vấn đề cụ thể.<br>- **Quyền điều khiển:** Do chương trình chủ động gọi khi cần.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Framework**<br>*(Khung sườn)*                  | - Là bộ khung được dựng sẵn chứa công cụ và thư viện.<br>- **Quyền điều khiển:** Do framework chủ động gọi code của bạn khi cần.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **IoC**<br>*(Inversion of Control)*              | - Đảo ngược quyền điều khiển: Thay vì ứng dụng tự quản lý thì giao nhiệm vụ cho framework quản lý luồng chạy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **DI**<br>*(Dependency Injection)*               | - **Mục đích:** Tạo ra liên kết lỏng (loose-coupling) nhằm dễ dàng thay thế các bộ phận khi cần.<br>- **Triển khai:**<br>&nbsp;&nbsp;1. Constructor Injection<br>&nbsp;&nbsp;2. Setter Injection<br>&nbsp;&nbsp;3. Field Injection                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Spring Container**                             | - **Đại diện:** `ApplicationContext`<br>- **Nhiệm vụ:**<br>&nbsp;&nbsp;1. Khởi tạo đối tượng.<br>&nbsp;&nbsp;2. Chứa đối tượng.<br>&nbsp;&nbsp;3. Thực hiện Injection (tiêm) các Object liên quan với nhau.<br>&nbsp;&nbsp;4. Quản lý vòng đời của Object.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Bean**                                         | - Là các đối tượng được chứa và quản lý trong Spring Container *(đối tượng bạn tự `new` thì không được gọi là Bean)*.<br>- **Cách định nghĩa:**<br>&nbsp;&nbsp;1. Gắn annotation lên class (`@Component`, `@Service`, `@Repository`, `@Controller`, `@RestController`).<br>&nbsp;&nbsp;2. Gắn annotation `@Bean` lên method của class có chứa `@Configuration`.                                                                                                                                                                                                                                                                                                                                                                                                 |
| **MVC**                                          | - Là mô hình thiết kế kiến trúc phần mềm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Spring MVC**                                   | - Là framework được thiết kế dựa trên kiến trúc MVC.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Luồng đi của 1 Request**                       | **1.** Client gửi Request (ví dụ: `GET /users`).<br>**2.** `DispatcherServlet` (Front Controller) tiếp nhận Request.<br>&nbsp;&nbsp;*(2.1. Tìm trong `HandlerMapping` để biết đưa cho Controller nào).*<br>**3.** `Controller` tiếp nhận.<br>**4.** `Controller` gọi `Service` xử lý logic.<br>**5.** `Service` gọi `Repository` chọc xuống Database lấy dữ liệu.<br>**6.** `Controller` đóng gói Dữ liệu (`Model`) và ném trả Tên Giao Diện cho `DispatcherServlet`.<br>**7.** `DispatcherServlet` gửi Tên Giao Diện tới `ViewResolver`.<br>**8.** `ViewResolver` tìm và trả về đường dẫn file View thực tế.<br>**9.** `DispatcherServlet` nhồi `Model` vào View để kết xuất ra HTML hoàn chỉnh.<br>**10.** Trả HTML về cho Trình duyệt của Client (Response). |
| **Chuyển nhận dữ liệu**<br>*(View ↔ Controller)* | - **Controller ➔ View:** Sử dụng interface `Model` và hàm `addAttribute("key", value)`.<br>- **View ➔ Controller:**<br>&nbsp;&nbsp;1. Đối với 1 param: `@RequestParam`<br>&nbsp;&nbsp;2. Đối với 1 object (form): `@ModelAttribute`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **⭐ SUMMARY**                                    | **Spring Core:** Quản lý luồng chạy (IoC) và tiêm phụ thuộc (DI) các Bean qua Spring Container để giảm phụ thuộc.<br>**Spring MVC:** `DispatcherServlet` điều phối Request tới Controller lấy Data, rồi qua ViewResolver kết xuất file HTML.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
