# Danh mục Từ vựng N5 Trọng tâm

> **Tóm tắt:** Tổng hợp từ vựng cần nhớ cho kỳ thi N5, phân loại theo loại từ và tối ưu hóa cho ôn tập chủ động.

## 📝 Cornell Note Table

| 💡 Phân loại / Gợi ý (Cue) | 📝 Nội dung ghi chú (Notes) |
| :--- | :--- |
| **🏠 Danh từ: Thời gian** | - 春 (Mùa xuân), 夏 (Mùa hè), 秋 (Mùa thu), 冬 (Mùa đông).<br>- 季節 (Kisettsu - Mùa), 台風 (Taifuu - Bão). |
| **🏠 Danh từ: Đời sống** | - 町 (Machi - Thị trấn), 仕事 (Shigoto - Công việc).<br>- 薬 (Kusuri - Thuốc), 独身 (Dokushin - Độc thân). |
| **🏃 Động từ: Cơ bản** | - 分かります (Hiểu), できます (Có thể).<br>- 思います (Nghĩ), 言います (Nói). |
| **🏃 Động từ: Hành động** | - 勉強します (Học), 登ります (Leo núi).<br>- 歌います (Hát), 洗います (Rửa). |
| **🏃 Động từ: Trạng thái** | - 住んでいます (Đang sống), 務めます (Làm việc tại).<br>- 役に立ちます (Yaku ni tachimasu - Có ích). |
| **✨ Tính từ: Dễ/Khó** | - かんたん (Dễ), むずかしい (Khó).<br>- あかるい (Sáng), くらい (Tối). |
| **✨ Tính từ: Trạng thái** | - 元気 (Khỏe), 安全 (An toàn).<br>- 忙しい (Bận), 長い (Dài). |
| **🔗 Phó từ & Katakana** | - じつは (Thật ra), ずっと (Suốt/Hơn nhiều).<br>- パソコン (PC), エンジニア (Engineer), ライブハウス. |

<br>

| 🎯 Tổng kết (Summary) |
| :--- |
| Tập trung vào các từ vựng chỉ trạng thái (住んでいる) và các phó từ mức độ (ずっと, できるだけ). Đây là những từ thường xuyên xuất hiện trong các bẫy đề thi N5. |
